## 📌 Project Overview

Behind every student record is a story shaped by academic performance, financial capacity, and personal circumstances. While some students successfully graduate, others struggle academically or leave the educational system.

This project explores patterns in student data to identify factors associated with **student dropout risk and academic success**. Through data analysis and interactive visualizations, the dashboard provides insights into academic, demographic, and socio-economic factors that may influence student outcomes.

The goal is to support **data-driven decision-making, early identification of at-risk students, and improved student retention strategies.**

## 📂 Dataset Information

This project uses the *Predict Students' Dropout and Academic Success* dataset, developed to support the analysis and prediction of student outcomes using machine learning techniques.

- 🎯 **Objective:** Analyze student outcomes (Dropout, Enrolled, Graduate)
- 🧑‍🎓 **Unit of Analysis:** Individual student records
- 📊 **Features:** Academic performance, demographic characteristics, and socio-economic factors
- 🏛 **Funding:** SATDAP Program – Capacitação da Administração Pública (Portugal)

The dataset underwent preprocessing to improve data quality, including handling anomalies and outliers.

## 🚀 Dashboard Features

### 📈 Key Performance Indicators (KPIs)
- Total Students
- Dropout Rate
- Graduation Rate

### 📊 Interactive Visualizations
- Admission Grade Distribution (Box Plot)
- Age Distribution (Violin Plot)
- Student Outcome Distribution (Donut Chart)
- Dropout Rate by Course and Gender (Heatmap)
- Dropout Contribution by Course (Treemap)

### 🎛 Interactive Filters
- Course Selection
- Gender Filtering
- Sorting Options

## 🛠️ Technologies Used

- **Python** – Data analysis and processing
- **Streamlit** – Interactive dashboard development
- **Pandas** – Data manipulation and preprocessing
- **Plotly** – Interactive data visualizations
- **Pillow** – Image processing and handling
